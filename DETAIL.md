# UTS Cyber Security challenge — from down unda

This is a UTS Cyber Security challenge from down unda, written in Aussie++.

The program starts with the numbers 1 through 26 and programatically:

1. removes every third number;
2. doubles every second remaining number;
3. reverses the resulting sequence;
4. cuts it in half; and
5. inserts `straya` halfway through it.

Run `flag.aussie` with the [Aussie++ interpreter](https://github.com/zackradisic/aussieplusplus).

Expected output:

```text
Flag: 52,25,46,22,40,19,34,16,28,straya,13,22,10,16,7,10,4,4,1,
```
